# Certifications

Parallel certification track for the Azure Cloud AI / LLM Architect path.

## Strategy
- **Build-first, cert-reinforcement-second.** Every roadmap day maps activities
  to specific cert domains. Cert prep is integrated, not separate.
- **Path:** AZ-900 → AI-102 (paced with build) → AZ-104 (parallel from Day 10–15) → AZ-305

## Folders
- `ai-102/` — Azure AI Engineer Associate (**Primary track now**)
- `az-104/` — Azure Administrator Associate
- `az-305/` — Azure Solutions Architect Expert
- `az-900/` — Azure Fundamentals
- `_shared/` — Cross-cert notes, vocabulary, patterns

## Conventions
Each cert folder has:
- `README.md` — exam overview, current status, study plan
- `objectives.md` — full skills-measured outline with progress checkmarks
- `study-notes/` — per-domain notes (e.g., `domain-1-plan-and-manage.md`)
- `practice/` — practice questions, explanations, weak areas
- `labs/` — hands-on labs that map to roadmap days

## Day → Cert Mapping
The roadmap day in `docs/notes/Day-NNN/summary.md` includes a "Certification
Reinforcement" section. After completing a day, add a one-liner to the
relevant cert's `study-notes/day-NNN-mapping.md` so the cert can reference
back to the build work.
