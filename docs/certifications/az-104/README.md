# AZ-104 — Azure Administrator Associate

## When this track activates

Around Day 10–15 of the roadmap, AZ-104 begins as a parallel cert track
ahead of the main AZ-305 push. Until then, AZ-104-relevant concepts are
flagged in each daily roadmap as Secondary reinforcement.

## Why before AZ-305

AZ-305 (Solutions Architect Expert) assumes operational fluency that AZ-104
provides: managing identities, networking, storage, compute, monitoring,
backup. Going straight to AZ-305 without AZ-104 is the single most common
reason candidates fail it.
