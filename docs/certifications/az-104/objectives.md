## Domain 1 — Manage Azure Identities and Governance (~20–25%)
- Manage Microsoft Entra users and groups
- Manage access to Azure resources (RBAC, role assignments, custom roles)
- Manage Azure subscriptions and governance (policies, locks, resource tags, cost management)
- Manage Azure Active Directory (tenants, B2B, MFA, Conditional Access)

## Domain 2 — Implement and Manage Storage (~15–20%)
- Configure Azure Storage accounts (redundancy, access tiers, lifecycle management)
- Configure Azure Blob Storage (containers, access levels, versioning, soft delete)
- Configure Azure Files and Azure File Sync
- Configure Azure Storage security (SAS tokens, stored access policies, encryption)
- Manage Azure Storage (import/export, Storage Explorer, AzCopy)

## Domain 3 — Deploy and Manage Azure Compute Resources (~20–25%)
- Automate deployment of VMs (templates, scripts, Azure Automation)
- Create and configure VMs (availability sets, scale sets, extensions)
- Create and configure containers (ACI, AKS basics)
- Create and configure Azure App Service (plans, deployment slots, TLS, custom domains)

## Domain 4 — Implement and Manage Virtual Networking (~15–20%)
- Configure virtual networks (subnets, private endpoints, service endpoints)
- Configure secure access to virtual networks (NSGs, Azure Bastion, VPN Gateway, ExpressRoute)
- Configure name resolution and load balancing (Azure DNS, Load Balancer, Application Gateway)
- Monitor and troubleshoot virtual networking (Network Watcher, connection monitor)

## Domain 5 — Monitor and Maintain Azure Resources (~10–15%)
- Monitor resources using Azure Monitor (metrics, alerts, action groups, workbooks)
- Implement backup and recovery (Azure Backup, Recovery Services vaults, MARS agent)
- Implement disaster recovery (Azure Site Recovery, VM replication)
