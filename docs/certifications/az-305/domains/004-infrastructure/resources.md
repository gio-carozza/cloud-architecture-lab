# Resources — Design Infrastructure Solutions (AZ-305 Domain 4)

---

## Official Microsoft Resources

- [AZ-305 Study Guide](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/az-305) — Authoritative domain breakdown; use to confirm which infrastructure design objectives are in scope (compute selection, application architecture, network, migration)
- [AZ-305: Design Infrastructure Solutions (Learning Path)](https://learn.microsoft.com/en-us/training/paths/design-infranstructure-solutions/) — Self-paced modules covering compute selection, application architecture patterns, and network design
- [Course AZ-305T00-A: Design Microsoft Azure Infrastructure Solutions](https://learn.microsoft.com/en-us/training/courses/az-305t00) — Official instructor-led course; use the application architecture and compute modules for batch/async patterns
- [Microsoft Certified: Azure Solutions Architect Expert](https://learn.microsoft.com/en-us/credentials/certifications/azure-solutions-architect/) — Certification landing page; links to both AZ-104 (prerequisite) and AZ-305 exam pages

## Exam Readiness

- [Preparing for AZ-305: Design Infrastructure Solutions (Part 4 of 4)](https://learn.microsoft.com/en-us/shows/exam-readiness-zone/preparing-for-az-305-04-fy25) — Microsoft exam readiness video covering Domain 4 objectives including compute selection and application architecture design
- [AZ-305 Design a Compute Solution (Module 2)](https://learn.microsoft.com/en-us/shows/on-demand-instructor-led-training-series/az-305-module-2a) — On-demand instructor session; covers recommending among VM, App Service, Functions, Container Apps, AKS, and Azure Batch for different workload shapes
