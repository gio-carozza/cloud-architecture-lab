# Day Mapping — Azure Architecture and Services (AZ-900 Domain 2)

| Day | Topics Covered |
|-----|----------------|
| Day-001 | Azure regions (East US chosen for latency + service availability); resource groups as logical containers for lifecycle management; subscriptions as billing + access boundaries; Azure Resource Manager (ARM) as the control plane behind every portal/CLI/API action; naming conventions as the operational discipline that makes ARM-level governance tractable |
| Day-002 | Azure App Service as a PaaS compute service: App Service Plan (the underlying compute tier), App Service (the application), and their relationship; resource group scoping — all lab resources in `rg-ai-lab-dev-eastus` for unified lifecycle management; Azure CLI as the ARM API wrapper used throughout the lab |
| Day-006 | Application Insights as an Azure Monitor feature (not a standalone service); Log Analytics workspace as the backing store for workspace-based App Insights; Azure Monitor as the umbrella platform for metrics, logs, and alerts across all Azure services |
