## Official Microsoft Resources

- [AZ-900 Study Guide](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/az-900) — Authoritative domain breakdown; confirms which management and governance topics are in scope for Domain 3
- [Azure Monitor documentation](https://learn.microsoft.com/en-us/azure/azure-monitor/overview) — Comprehensive reference for metrics, logs, alerts, and Application Insights
- [Application Insights overview](https://learn.microsoft.com/en-us/azure/azure-monitor/app/app-insights-overview) — Covers workspace-based vs. classic, SDK options, and telemetry types

- [Migrate to workspace-based Application Insights](https://learn.microsoft.com/en-us/azure/azure-monitor/app/convert-classic-resource) — Official migration guide from classic to workspace-based
