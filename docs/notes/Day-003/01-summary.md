# Day 3 – Azure Well-Architected Framework

## Objective

Understand and apply the 5 pillars of the Azure Well-Architected Framework to my lab.

## Key Insight

The framework is not about perfection — it is about tradeoffs.

Every architecture decision impacts:

- reliability
- security
- cost
- performance
- operations

## Biggest Realization

My current lab is NOT architected yet.

It is:

- a foundation
- not a system

## Shift in Thinking

Before: "How do I build this?"
Now: "What could go wrong if I build this?"
